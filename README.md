#  数独解法アルゴリズムおよびカメラ認識の実装
本プロジェクトは、数独（ナンプレ）を解くための多機能Pythonアプリケーションです。 単なる機械的な全探索（バックトラック）だけでなく、人間が実際にパズルを解く際に用いる**11種類の論理的解法**（ロジックを実装しています。 さらに、Webカメラを用いて紙の数独をリアルタイムで認識し、解答を拡張現実（AR）として画面上に投影する機能を備えています。

## 主な機能(Features)
**1. バックトラック**
- 再帰関数を用いた深さ優先探索による解法です。

**2. 人間的推論アプローチ**
- 「obvious single」から「X-Wing」「Swordfish」などの上級テクニックまで、11種類のロジックを実装。
- 人間と同じように各マスの「候補数字（メモ）」を管理・更新し、論理的にマスを埋めていく過程をシミュレートします。
- どのロジックで解けたか、どのロジックが使用されたかの統計情報を出力可能です。

**3. ARカメラソルバー**
- カメラに写っている数独盤面を自動で認識します。
- 解いた数字を元の映像の座標系に逆変換し、盤面に追従する形でオーバーレイ表示します。
- 人間的推論アプローチで解を絞り込み、バックトラックを実行することで高速に解を求めます。

## 実行方法(Usage)
プロジェクトのルートディレクトリ（sudoku/）で以下のコマンドを実行してください。
1. バックトラック解法
ロジックを使用せず、機械的な全探索で解を導きます。  
**python -m src.backtrack_solver**
<br><br>
2. 人間的推論アプローチ
テキストファイルから問題を読み込み、ロジックを駆使して解きます。解法プロセスの検証やロジック強度のテストに使用します。  
**python -m src.human_solver**
<br><br>
3. ARカメラソルバー
Webカメラを起動し、手元の数独を認識して解答を表示します。  
**python -m src.camera_solver**  
【実行方法】 
    - Space キー: 盤面の取り込み・数字認識（認識中は緑の枠が表示されます）
    - s キー: ソルバー実行・AR解答表示
    - c キー: リセット（新しい問題を読み込む場合）
    - q キー: 終了

| 優先順位 | ロジック名 | 概要 |
| :--- | --- | --- |
| 1 | Obvious Singles(明らかなシングル) | メモの候補が1つだけのマスを確定 |
| 2 | Obvious Pair(明らかなペア) | 同一ユニット内の2マスで候補が2つ |
| 3 | Obvious Triple(明らかなトリプル) | 同一ユニット内の3マスで候補が3つ |
| 4 | Hidden Singles(隠れたシングル) | ユニット内でその数字が入る場所が1つ |
| 5 | Hidden Pair(隠れたペア) | 特定の2数字が特定の2マスのみに出現 |
| 6 | Hidden Triple(隠れたトリプル) | 特定の3数字が特定の3マスのみに出現 |
| 7 | Pointing Pair(ポインティングペア) | ブロック内の候補が直線上に並ぶ |
| 8 | Pointing Triple(ポインティングトリプル) | Pointing Pairの3数字版 |
| 9 | X-Wing(Xウィング) | 長方形を形成する候補の関係を利用 |
| 10 | Y-Wing(Yウィング) | 3つのマスの連鎖関係を利用 |
| 11 | Swordfish(カジキ) | 3行3列の関係を利用したX-Wingの拡張 |

## 実行結果(Results)
バックトラック、人間的推論アプローチは59問のテストデータセットを用いてテストを行い、実行結果は以下の通りです。
1. バックトラック
    - 正答率: 100% (59/59問)
    - 平均実行時間: 約127秒
2. 人間的推論アプローチ
    - 正答率: 88.1% (52/59問)
    - 平均実行時間: 約0.15秒

カメラモード（AR）では、ロジックで解ききれない場合（残り約11%）にバックトラックへに移行する「ハイブリッド方式」 を採用しているため、実質的な正答率は100%、かつバックトラック単体の実行よりも早い応答を実現しています。
